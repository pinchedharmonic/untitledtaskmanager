# Untitled Task Manager 0.1.0 (build 1)

- Windows x64: extract `UntitledTaskManager-0.1.0-Windows-x64.zip`, then run `untitledtaskmanager.exe`. Keep the extracted files together.
- Android: install `UntitledTaskManager-0.1.0-Android.apk` on the phone. Sign in with the existing Supabase account to load synced lists and tasks.

Both packages were built in release mode with the project's Supabase URL and publishable key supplied at build time.
